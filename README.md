# 小磊 · 个人作品集

一个简洁、响应式的个人作品集单页网站，用于展示软件工程、AI 辅助开发与 Web 应用等项目作品。

## 项目功能

- **作品集展示**：以数据驱动的方式渲染项目列表，支持代表作放大展示
- **深浅色主题切换**：顶部导航栏一键切换浅色 / 深色主题，并通过 localStorage 记住用户上一次的选择
- **图片放大预览**：点击项目配图可打开全屏遮罩预览
- **滚动导航高亮**：浏览页面时左侧导航自动高亮当前所在区块
- **移动端适配**：窄屏下自动切换为上下布局，并通过汉堡菜单展开导航

## 技术栈

- 原生 HTML5
- 原生 CSS3（CSS 变量实现主题配色，桌面端 + 移动端响应式布局）
- 原生 JavaScript（ES5 语法，无框架、无第三方依赖）

## 运行方式

本项目为纯静态站点，无需构建，直接以任意静态服务器打开即可。

```bash
# 方式一：直接用浏览器打开
# 双击 index.html 即可

# 方式二：本地静态服务器访问
python3 -m http.server 8080
# 或
npx serve .
# 浏览器访问 http://localhost:8080
```

## 目录结构

```
lab04/
├── index.html            # 页面结构（含侧边栏、各内容区块、图片预览遮罩层）
├── css/
│   └── style.css         # 全部样式（含深色主题变量覆盖）
├── js/
│   ├── projects-data.js  # 项目数据，新增项目时在此数组中追加
│   └── script.js         # 交互逻辑：主题切换、项目渲染、导航高亮、菜单开合、图片预览
└── README.md
```

## 主要功能细节

- **数据驱动项目列表**：项目内容集中在 `js/projects-data.js`，新增项目只需在 `PROJECTS` 数组中追加一条记录。
- **主题记忆**：主题选择通过 `localStorage` 持久化，刷新页面或下次访问仍保留用户偏好。
- **可访问性**：导航、菜单、图片预览等交互均带 `aria` 标签与键盘支持。
